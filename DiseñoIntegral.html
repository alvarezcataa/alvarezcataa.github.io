Quiero esto para mi espacio

¡Importante!

Este servicio está diseñado para darte autonomía. Por eso, no incluye dirección de obra, visitas presenciales, gestión de gremios ni trámites municipales.

La documentación entregada es un legajo técnico de diseño, pero necesita verificación in situ para ser ejecutable. No incluye ningún tipo de cálculo estructural.

Los valores en el presupuesto son estimados de referencia, el costo final dependerá de tus elecciones al momento de comprar materiales o contratar mano de obra.

Preguntas Frecuentes

¿Cómo sé si este servicio es para mí?

Es para vos si buscás unificar el diseño de tu casa o remodelar espacios existentes. Ideal para obtener soluciones hechas a medida con el respaldo técnico necesario para hacerse realidad.

¿Qué necesito preparar antes de la asesoría?

Solo debes completar el formulario de relevamiento para enviarnos las fotos y medidas de tu espacio. Te guiamos en el proceso de registrar las medidas, pero vas a necesitar una cinta métrica para completar este paso.

¿Incluye acompañamiento durante la obra?

Este servicio no incluye dirección ni acompañamiento de obra. Te entregamos el mapa de ejecución completo para que puedas delegar la dirección de obra o para que tus trabajadores de confianza sepan ejecutar de forma autónoma.

¿Cuántos espacios puedo consultar por diseño?

Podes proyectar un ambiente o sumar espacios para unificar la estética de tu casa entera. El servicio se presupuesta de forma personalizada, según la escala y complejidad de tu encargo.

¿En cuánto tiempo recibo mi Plan de Ejecución?

El plazo se especifica en la cotización según la complejidad del proyecto, aunque el tiempo estimado de entrega es de un mes.
